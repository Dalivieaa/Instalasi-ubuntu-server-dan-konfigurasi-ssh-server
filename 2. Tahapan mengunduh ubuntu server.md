## Tahapan Instalasi Ubuntu Server di VirtualBox

| No | Langkah  | Detail |
| :---: | :--- | :--- |
| **1** | `Cari Installer` | Buka browser, cari **"putty download"** untuk persiapan remote |
| **2** | `Unduh PuTTY` | Buka web resmi `chiark.greenend.org.uk` $\rightarrow$ unduh installer **64-bit x86** |
| **3** | `Bahasa Sistem` | Masuk ke VirtualBox $\rightarrow$ pilih **Bahasa Indonesia** untuk sistem Linux |
| **4** | `Layout Keyboard` | Atur tata letak keyboard ke **English (US)** $\rightarrow$ pilih **Done** |
| **5** | `Pilih Varian` | Pilih **Ubuntu Server** $\rightarrow$ pilih **Done** |
| **6** | `Koneksi Jaringan` | Cek status jaringan Virtual Machine $\rightarrow$ pilih **Done** |
| **7** | `Konfigurasi Proxy` | Kosongkan jika tidak memakai internet khusus $\rightarrow$ pilih **Done** |
| **8** | `Mirror Archive` | Tunggu verifikasi alamat mirror download $\rightarrow$ pilih **Done** |
| **9** | `Pengaturan Disk` | Pilih **Use an entire disk** $\rightarrow$ pilih **Done** |
| **10** | `Partisi Disk` | Periksa laporan pembagian hard disk $\rightarrow$ pilih **Done** |
| **11** | `Konfirmasi Format` | Pilih **Continue** *(Aman: hanya menghapus virtual disk)* |
| **12** | `Profil User` | Isi Nama, Nama Server, Username, dan Password |
| **13** | `Konfirmasi Profil` | Gulir ke paling bawah $\rightarrow$ tekan **Done** |
| **14** | `Proses Instalasi` | Tunggu hingga selesai dan muncul opsi **Reboot Now** |
| **15** | `Login Pertama` | Masukkan **Username** dan **Password** yang telah dibuat |
| **16** | `Instalasi Selesai` | Sistem Ubuntu Server sudah 100% siap digunakan |
| **17** | `Tes Perintah Dasar` | Ketik `ls` *(lihat isi folder)* atau `ssh` *(koneksi jaringan)* |
| **18** | `Install PuTTY (Host)` | Jalankan installer PuTTY di Windows $\rightarrow$ klik **Next** |
| **19** | `Lokasi Folder` | Tentukan lokasi direktori instalasi $\rightarrow$ selesaikan setup |
