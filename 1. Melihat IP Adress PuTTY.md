# Panduan PuTTY & Cek IP Address

| No |  Langkah |  Detail |
| :---: | :--- | :--- |
| **1** | `Jalankan Installer` | Klik **Install PUTTY files** |
| **2** | `Konfirmasi Izin` | Klik **Yes** saat pop-up izin muncul |
| **3** | `Proses Instalasi` | Tunggu indikator status bar hijau selesai |
| **4** | `Selesai` | Klik tombol **Finish** |
| **5** | `Cek IP (Windows)` | `Win + R` $\rightarrow$ ketik `cmd` $\rightarrow$ jalankan `ipconfig` |
| **6** | `Cek IP (Linux)` | Ketik `hostname -I` pada terminal Linux |
| **7** | `Buka Aplikasi` | Jalankan aplikasi PuTTY |
| **8** | `Input Host Name` | Masukkan IP Linux: `10.0.2.15` |
| **9** | `Login Credentials` | **Username:** `ubuntu`<br>**Password:** `ubuntu` |
